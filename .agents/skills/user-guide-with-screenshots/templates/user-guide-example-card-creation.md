# How to Use: Add a New Flashcard

> Last updated: 2026-08-20

## What does this feature do?

While studying a vocabulary deck, you can add new words at any time — not just
the term and its meaning, but also pronunciation, example sentences, collocations,
and memory tips. As you type, you see a live preview of the card exactly as it
will look when saved.

## How to use it

### Step 1: Open the deck you want to add a word to

![Deck detail page](../user-guides/assets/card-creation/01-deck-detail-page.png)

Open the deck you want to study. You'll see the total card count broken down by
New / Learning / Mastered, along with a search bar if the deck already has many
cards.

### Step 2: Click "Add new card"

![Add card dialog](../user-guides/assets/card-creation/02-open-add-card-dialog.png)

A popup window appears with two panels: the left side is where you enter
information, and the right side shows a live preview of the card — click the
card preview to flip between the front and back.

### Step 3: Fill in the details and watch the live preview

![Filled form with preview](../user-guides/assets/card-creation/03-fill-form-and-preview.png)

Only the term and meaning are required to save a card. For a richer card, you
can also add an example sentence, collocations, or a memory tip. Everything you
type appears immediately on the card preview on the right.

### Step 4: If the word already exists, you'll get a gentle warning

![Duplicate word warning](../user-guides/assets/card-creation/04-duplicate-warning.png)

The system highlights the input if the term you're typing already exists in this
deck (case-insensitive), so you don't accidentally add the same word twice. You
can still save if you want to keep both cards.

## Tips

- To hear how a word is pronounced, click the 🔊 icon next to the term field.
- If you need to add many cards in a row, use the "Save & add another" button —
  it saves the current card and immediately clears the form so you can type the
  next word without reopening the dialog.

## Frequently asked questions

**Q:** Do I have to fill in the example sentence or memory tip?
**A:** No. Only the term and meaning are required; all other fields are optional.

**Q:** What happens if I accidentally add a duplicate?
**A:** You'll see the warning as you type, but the system won't block you from
saving — you decide whether to keep both cards or not.

## Not yet supported

- AI cannot auto-fill card details yet — you need to type them manually.
- Bulk import from Excel or Anki files is not available yet — this will be added in a future update.
