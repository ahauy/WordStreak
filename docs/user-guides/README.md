- **Ảnh chụp thực tế 100%**: Sử dụng ảnh chụp màn hình từ ứng dụng thật, có viền khoanh đỏ (`#EF4444`) và huy hiệu số thứ tự (**①, ②, ③**) tương ứng trực tiếp với từng bước thao tác trong bài viết.
- **Tính khả thi & Mẹo thực chiến**: Cung cấp đầy đủ phím tắt thao tác nhanh, cơ chế tính điểm thưởng XP và giải đáp thắc mắc thường gặp (FAQ).
